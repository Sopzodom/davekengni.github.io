# Dave Kengni Portfolio - GitHub Pages

## Publish
1. Create or open the repository `davekengni.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In **Settings > Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Replace `YOUR_EMAIL@example.com` in `index.html` and add your Fiverr and LinkedIn links.

The site is responsive, static, and requires no framework or build step.
